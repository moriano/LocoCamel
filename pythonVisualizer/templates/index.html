Camel Route Visualizer

A Flask-based application for visualizing Apache Camel routes via Jolokia

Available Endpoints:

GET /routes
Get a list of all Camel routes in the system (by ID)
GET /route/<route_id>
Get detailed information about a specific route
Example: /route/hello-route
GET /route/<route_id>/graph
Get SVG visualization of the route
Example: /route/hello-route/graph
Note: Make sure your Camel application is running on port 8080 with Jolokia enabled (dev profile).
